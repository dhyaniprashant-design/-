# एनएचपीसी हिंदी कार्यशाला रिकॉर्ड सेटअप

यह एक सरल `HTML + JavaScript` आधारित सेटअप है, जिससे हिंदी कार्यशालाओं का रिकॉर्ड आसानी से मेनटेन किया जा सकता है।

## सुविधाएँ
- ड्रॉपडाउन से चयन:
  - कार्यशाला स्तर (विभागीय, नराकास, ऑनलाइन)
  - आयोजन इकाई
  - माध्यम (ऑफलाइन/ऑनलाइन/हाइब्रिड)
- तिथि के लिए Date Picker
- प्रतिभागियों की संख्या (numeric field)
- टिप्पणी फ़ील्ड
- रिकॉर्ड सूची (टेबल फॉर्मेट)
- रिकॉर्ड हटाने की सुविधा
- सभी रिकॉर्ड एक क्लिक में साफ़ करने की सुविधा
- CSV डाउनलोड (Excel में खोलने योग्य)

## उपयोग कैसे करें
1. `workshop_tracker.html` को किसी भी ब्राउज़र में खोलें।
2. फॉर्म भरकर **रिकॉर्ड सहेजें** पर क्लिक करें।
3. रिकॉर्ड नीचे टेबल में दिखेंगे।
4. `CSV डाउनलोड` पर क्लिक करके पूरा डेटा Excel के लिए निर्यात करें।

## डेटा कहाँ सेव होगा?
- डेटा ब्राउज़र के `LocalStorage` में सेव होता है।
- यदि सिस्टम/ब्राउज़र बदलते हैं तो डेटा अपने आप ट्रांसफर नहीं होगा।
- नियमित बैकअप के लिए CSV डाउनलोड लेते रहें।

## आगे का विस्तार (यदि चाहिए)
- यूजर लॉगिन आधारित वेब ऐप
- MySQL/SQL Server में सेंट्रल डेटाबेस
- विभाग/प्रोजेक्ट-वार डैशबोर्ड
- तिमाही/वार्षिक राजभाषा रिपोर्ट ऑटो-जनरेशन
