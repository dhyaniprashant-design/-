# एनएचपीसी हिंदी कार्यशाला रिकॉर्ड सेटअप

यह एक सरल `index.html` आधारित सेटअप है जिसमें हिंदी कार्यशालाओं का रिकॉर्ड रखा जा सकता है:

- कार्यशाला स्तर चयन हेतु ड्रॉपडाउन
- कार्यशाला तिथि हेतु डेट पिकर
- कार्मिकों की संख्या हेतु नंबर फ़ील्ड
- Local Storage में रिकॉर्ड सेव
- CSV डाउनलोड सुविधा

## उपयोग

1. `index.html` को किसी भी ब्राउज़र में खोलें।
2. फ़ॉर्म भरकर **रिकॉर्ड सेव करें**।
3. रिकॉर्ड नीचे तालिका में दिखेंगे।
4. आवश्यक होने पर **CSV डाउनलोड करें**।

> नोट: डेटा ब्राउज़र-आधारित Local Storage में रहता है।
